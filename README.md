# 政策通 · 小微企业政策助手（静态演示版）

把散落在各级政府网站里的创业扶持政策，变成看得懂、查得到、能照着办的行动清单。

这是参赛演示用的**纯静态站点**：没有后端、没有构建步骤，双击 `index.html` 就能用，也可以直接部署到任意静态托管（GitHub Pages / Netlify / 对象存储）。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 首页：价值主张、三项能力、热门政策、示例问答 |
| `policies.html` | 政策库：关键词搜索 + 层级/主题筛选 + 只看仍可申报 |
| `policy-*.html` | 政策详情：解读 / 原文双 Tab，条款级跳转与高亮 |
| `chat.html` | 问答：浏览器内 BM25 条款检索，答案带〔政策·第X条〕引用 |
| `plan.html` | 路径规划：6 题问卷 → 匹配政策 + 12 个月行动时间轴 |

问答是**离线**的：检索与作答都在浏览器里完成，不需要 API Key、不需要联网。接上大模型后可以换成顾问式回答，引用规则不变。

## 本地打开

直接双击 `index.html`，或起一个静态服务器：

```bash
python -m http.server 8000
# http://localhost:8000
```

## 数据说明

- 收录 6 条政策：4 条全国性政策（小型微利企业所得税、小规模纳税人增值税、研发费用加计扣除、创业担保贷款、优质中小企业梯度培育）+ 1 条地区级示例条目。
- 全国性政策的条款要点按公开口径整理，页面上标注「原文待核对」，文号与发布日期请在官方渠道复核。
- 标注「示例数据」的条目为演示用虚构内容，**请勿据此申领**。
- 本产品不构成法律或税务意见；实际办理以主管部门审核为准。
