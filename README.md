# 政策通 · 湖南小微创业者政策助手

把散落在省政府、税务、人社、工信、发改各厅局网站上的扶持政策，变成看得懂、查得到、能照着办的行动清单。

这是参赛演示用的**纯静态站点**：没有后端、没有构建步骤，双击 `index.html` 就能用，也可以直接部署到任意静态托管。

## 在线访问

- 站点：https://tmdaz.github.io/policy-tong/
- 问答直链：https://tmdaz.github.io/policy-tong/chat.html?demo=1
- 开发者模式：https://tmdaz.github.io/policy-tong/dev.html

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 首页：湖南定位、三项能力、官方入口、热门政策、示例问答 |
| `policies.html` | 政策库：地区（湖南 / 全国）+ 层级 + 主题筛选 + 关键词检索 |
| `policy-*.html` | 政策详情：解读 / 原文双 Tab，条款级跳转与高亮 |
| `chat.html` | 问答：浏览器内 BM25 条款检索，答案带〔政策·第X条〕引用 |
| `plan.html` | 路径规划：行业/市州/规模等问卷 → 匹配政策 + 12 个月行动时间轴 |
| `dev.html` | 开发者模式：粘贴长文自动切条款、生成并下载结构化 JSON |

问答是**离线**的：检索与作答都在浏览器里完成，不需要 API Key、不需要联网。接上大模型后可换成顾问式回答，引用规则不变。

## 政策从哪来（重要）

**原文的检索与下载由人工完成**，本站只做导航与结构化，不代抓、不转述、不臆造。首页提供五个官方入口，
拿到 PDF / DOC 后用「开发者模式」导入，条款即进入政策库并可被问答引用。

导入分两条路：

1. **浏览器**：`dev.html` → 粘贴全文 → 自动切分 → 补元信息 → 下载 JSON。
2. **命令行**：`npm run import -- --file 政策.pdf --id xxx --region 湖南省 --url <官方链接>`，支持 `.pdf / .docx / .txt / .md`，产出带 `needsReview` 的草稿。

人工补全解读（谁能享受 / 材料 / 时限 / 去哪办）并核对原文后，把文件移入 `src/data/policies/`，重新构建即可上线。

